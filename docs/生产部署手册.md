# 企业AI智能办公系统 — 生产部署手册

> 适用版本：monorepo（admin-server / ai-service / frontend / frontend-admin / deploy）
> 目标环境：国内云服务器（单机 docker-compose），HTTP 内网运行（HTTPS/域名后置，Caddy 可预留）

## 一、前置条件

| 项 | 要求 |
|---|---|
| 服务器 | Linux x86_64，≥4C8G，磁盘 ≥80G（文件存储 + 数据库 + 镜像） |
| 软件 | Docker ≥ 24 + Docker Compose v2 |
| 网络 | 可拉取 Docker Hub 镜像（或已配置国内加速） |
| 仓库 | `zhb0829/enterprise-ai-office-system`（main 分支） |

## 二、首次部署（10 步）

```bash
# 1. 克隆仓库
git clone https://github.com/zhb0829/enterprise-ai-office-system.git
cd enterprise-ai-office-system

# 2. 生成环境配置
cd deploy
cp .env.example .env

# 3. 编辑 .env —— 全部必填项见下文第三节
vi .env

# 4. 一键拉起（首次会本地构建镜像，约 5~15 分钟；开通 ACR 后直接拉取镜像）
docker compose up -d

# 5. 查看首启随机管理员密码（第 17 项安全设计：不使用默认密码）
docker logs eaos-admin-server 2>&1 | grep "初始密码"

# 6. 验证
curl http://localhost/api/health                 # Java 网关 → 200
curl http://localhost/api/notifications/unread-count   # → 401（未认证，正常）

# 7. 浏览器访问
#    用户工作台:  http://<服务器IP>/
#    管理控制台:  http://<服务器IP>/admin/

# 8. 使用随机密码登录 admin → 系统强制要求修改密码
# 9. （管理端）系统管理 → 用户管理：创建业务账号、分配角色
# 10. （管理端）系统管理 → 通知渠道：按需配置 Webhook/邮件渠道
```

## 三、.env 必填项说明

> admin-server 启动时会 fail-fast 校验密钥：空值、`change-me` 占位、历史默认值都会拒绝启动。

| 变量 | 说明 | 生成建议 |
|---|---|---|
| `POSTGRES_PASSWORD` | 数据库密码 | `openssl rand -base64 24` |
| `JWT_SECRET` | JWT 签名密钥（≥32 字符） | `openssl rand -hex 32` |
| `AI_INTERNAL_TOKEN` | Java↔Python 服务间令牌（≥16） | `openssl rand -hex 16` |
| `OPINION_INTERNAL_TOKEN` | 舆情模块服务间令牌（≥16） | `openssl rand -hex 16` |
| `MEETING_INTERNAL_TOKEN` | 会议模块服务间令牌（≥16） | `openssl rand -hex 16` |
| `CORS_ALLOWED_ORIGINS` | 前端来源（逗号分隔） | 换成正式域名 |
| `LLM_API_KEY` | DeepSeek/OpenAI 兼容密钥 | LLM 供应商控制台 |
| `EMBEDDING_API_KEY` | 向量化服务密钥 | 同上 |
| `GRAFANA_ADMIN_PASSWORD` | Grafana 管理密码 | 自定义 |
| `GRAFANA_ALERT_EMAILS` | 告警收件邮箱 | 运维邮箱 |
| `ACR_REGISTRY` | 镜像仓库地址 | ACR 开通后替换 |

## 四、服务拓扑

```
用户/浏览器
   │ :80
   ▼
gateway (nginx)
   ├── /            → frontend        (用户工作台, Vue3)
   ├── /admin/      → frontend-admin  (管理控制台, Vue3, base=/admin/)
   ├── /api/        → admin-server    (Spring Boot 3, 认证/网关/管理业务, :8080)
   │                     └── /internal 反代 → ai-service (FastAPI, :8000)
   └── /static/     → ai-service      (导出文件/上传附件)

数据面:  db (pgvector/pg16) ←─ Flyway V1~V3
         file-storage volume  (Java /data/storage/java + Python /data/storage/{uploads,exports})
观测面:  prometheus / grafana(:3000) / loki / promtail / node-exporter
```

## 五、观测与告警

- Grafana：`http://<IP>:3000`（账号 admin / `.env` 中的 `GRAFANA_ADMIN_PASSWORD`）
- 日志检索：Loki 数据源，按 `{container="eaos-admin-server"}` 过滤，日志行内含 `[traceId]`
- 全链路排障：浏览器 Network 复制响应头 `X-Trace-Id` → Grafana Explore 检索该 traceId，可同时命中 Java 与 Python 日志
- 内置告警（EAOS 文件夹）：服务下线、5xx 率、LLM P95、磁盘 >80%；SMTP 配置后自动邮件通知

## 六、日常运维

```bash
docker compose ps                      # 服务状态
docker compose logs -f admin-server    # 跟日志
docker compose restart admin-server    # 重启单服务
docker compose pull && docker compose up -d   # ACR 开通后：拉镜像滚动升级
```

- **备份**：`pgdata` 与 `file-storage` 两个 volume 是唯一状态，建议每日快照
  （`docker run --rm -v eaos_pgdata:/data -v /backup:/backup alpine tar czf /backup/pgdata-$(date +%F).tgz /data`）
- **扩容注意**：单机 volume 架构下不可水平扩展 Java 实例；多实例前须先切换 `FileStorage` 为对象存储实现（接口已预留）

## 七、故障排查

| 现象 | 排查 |
|---|---|
| admin-server 起不来，日志有"密钥未配置，拒绝启动" | `.env` 缺少必填密钥，见第三节 |
| 登录提示"用户名或密码错误" | 首启密码见 `docker logs eaos-admin-server | grep 初始密码` |
| 页面空白/资源 404 | 清浏览器缓存后强刷；确认访问的是 `/` 或 `/admin/` 前缀 |
| AI 功能报"AI 服务暂时不可用" | `docker compose logs ai-service`；检查 `LLM_API_KEY` |
| 上传失败 413 | nginx `client_max_body_size 500m` 已配置，检查前置 LB 是否覆盖 |
