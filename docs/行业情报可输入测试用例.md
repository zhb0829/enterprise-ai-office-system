# 行业情报可输入测试用例

## 测试地址

- 管理端：`http://localhost:5174/admin/intelligence`
- 用户端：`http://localhost:5175/workspace/intelligence`

## 推荐执行顺序

1. 先执行 TC-A-01、TC-A-04，创建并采集 `Hacker News 新文章测试`。
2. 再执行 TC-A-06，生成日报。
3. 完成后执行 TC-U-01 至 TC-U-11。
4. 最后执行 TC-A-02、TC-A-03、TC-A-05 和 TC-B-01 至 TC-B-04，验证扩展与异常场景。

说明：关键词、主题和条目数量会随实时采集结果变化。涉及内容筛选的用例以“结果均满足条件、页面状态正确”为准，不要求固定数量。

## 一、管理端来源表单

### TC-A-01 新增 Hacker News RSS 来源

在“新增采集来源”表单中输入：

| 字段 | 输入值 |
| --- | --- |
| 来源名称 | `Hacker News 新文章测试` |
| 来源类型 | `RSS` |
| 来源 URL | `https://hnrss.org/newest` |
| 关键词 | 留空 |
| 竞争对手 | 留空 |
| 采集频率 | `手动` |

点击“添加来源”。预期：来源保存成功，来源列表出现新记录，健康状态初始为 `unknown`。

### TC-A-02 新增 arXiv Atom 来源

| 字段 | 输入值 |
| --- | --- |
| 来源名称 | `arXiv 计算语言学测试` |
| 来源类型 | `RSS` |
| 来源 URL | `https://export.arxiv.org/api/query?search_query=cat:cs.CL&start=0&max_results=20&sortBy=submittedDate&sortOrder=descending` |
| 关键词 | `LLM,agent,language model` |
| 竞争对手 | 留空 |
| 采集频率 | `每日` |

点击“添加来源”。预期：保存成功，关键词按逗号拆分为 3 项。

### TC-A-03 关键词拦截采集

| 字段 | 输入值 |
| --- | --- |
| 来源名称 | `Hacker News AI 关键词测试` |
| 来源类型 | `RSS` |
| 来源 URL | `https://hnrss.org/frontpage` |
| 关键词 | `AI,LLM,agent` |
| 竞争对手 | `OpenAI,Anthropic` |
| 采集频率 | `手动` |

手动采集后预期：新增条目的标题或摘要至少包含一个关键词；不匹配的条目不进入结果。

### TC-A-04 手动采集成功

1. 在来源列表找到 `Hacker News 新文章测试`。
2. 点击“立即采集”。
3. 点击“刷新任务”。

预期：任务状态从 `queued/running` 变为 `success`，新增条目数大于 0，来源健康状态变为 `healthy`。

### TC-A-05 失败任务重试

新增以下测试来源：

| 字段 | 输入值 |
| --- | --- |
| 来源名称 | `失败重试测试来源` |
| 来源类型 | `RSS` |
| 来源 URL | `https://example.invalid/not-found.xml` |
| 关键词 | 留空 |
| 竞争对手 | 留空 |
| 采集频率 | `手动` |

点击“立即采集”，刷新任务后点击“重试”。预期：任务状态为 `failed`，页面显示错误信息和重试次数增加。

### TC-A-06 生成日报

1. 确认至少有一个成功采集任务。
2. 点击“生成日报”。
3. 点击“刷新数据”。

预期：简报列表出现一条 `daily` 记录，显示覆盖条目数、主题数和按当前浏览器当地时间换算后的生成时间；点击该简报可展开查看主题摘要与引用来源，再次点击可收起。

## 二、用户端筛选与查看

### TC-U-01 初始数据加载

打开用户端页面，不输入任何内容，直接等待加载完成。

预期：显示匹配条目、主题聚类、情报简报三个区域；当前已有测试数据时，匹配条目数应大于 0。

### TC-U-02 关键词筛选

在“关键词”输入框输入：

```text
MCP
```

点击“应用筛选”。预期：条目列表只显示标题或摘要中包含 `MCP` 的结果。

### TC-U-03 arXiv 关键词筛选

在“关键词”输入框输入：

```text
agent
```

点击“应用筛选”。预期：结果数量发生变化，列表中显示 AI agent 或相关论文条目。

### TC-U-04 来源筛选

在“来源”下拉框选择：

```text
Hacker News 新文章测试
```

点击“应用筛选”。预期：所有条目的来源均为 Hacker News，切换回“全部已加载来源”后恢复全部结果。

### TC-U-05 关键词与来源组合筛选

| 字段 | 输入值 |
| --- | --- |
| 关键词 | `AI` |
| 来源 | `Hacker News 新文章测试` |

点击“应用筛选”。预期：同时满足来源和关键词条件，结果数量不大于单独筛选结果。

### TC-U-06 重置筛选

先完成 TC-U-05，再点击“重置”。预期：关键词清空、来源恢复全部，条目列表恢复默认结果。

### TC-U-07 主题过滤

在“过滤主题”输入框输入：

```text
agent
```

预期：主题聚类列表只显示主题名称中包含 `agent` 的聚类。

### TC-U-08 单篇摘要

在任意文章上点击“单篇摘要”。预期：右侧摘要区域显示摘要、风险提示和原文引用链接。

### TC-U-09 主题摘要

点击一个主题聚类。预期：右侧显示该主题的摘要，引用来源数量与主题关联条目相符。

### TC-U-10 日报查看

在“日报与周报”区域选择 `日报`，点击一条简报。预期：展开后显示覆盖条目数、主题数和主题摘要；再次点击可收起。

### TC-U-11 分页加载

在未筛选状态下点击“加载更多”。预期：保留当前条目并追加下一页，不出现重复条目，显示数量增加。

## 三、边界输入

### TC-B-01 必填项为空

来源名称留空，其他字段正常填写后提交。预期：浏览器阻止提交或页面提示来源名称不能为空。

### TC-B-02 URL 格式错误

来源 URL 输入：

```text
not-a-url
```

预期：浏览器提示 URL 格式错误，不能保存。

### TC-B-03 关键词空格和重复逗号

关键词输入：

```text
 AI, ,LLM,, agent 
```

预期：保存后应得到有效关键词 `AI`、`LLM`、`agent`，空项被忽略。

### TC-B-04 无匹配结果

用户端关键词输入：

```text
不存在的测试关键词-20260822
```

预期：显示“暂无匹配的情报条目”，页面不白屏、不报错。
