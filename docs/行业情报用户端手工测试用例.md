# 行业情报用户端手工测试用例

## 测试环境

- 用户端：`http://localhost:5175/workspace/intelligence`
- Java 网关：`http://localhost:8080`
- Python AI 服务：`http://localhost:8000`
- 测试日期：2026-08-22

## 测试数据准备

1. 在管理端的“情报聚合”页面新增至少 2 个启用中的采集源，其中至少一个为 RSS 源。
2. 对采集源执行“手动采集”，等待任务状态为“成功”。
3. 确认已采集至少 3 条不同主题的情报；如需验证“加载更多”，准备超过 20 条条目。
4. 在管理端分别生成一份“日报”和“周报”。

当前数据库没有已采集条目时，可以先执行 TC-INT-01、TC-INT-02、TC-INT-10、TC-INT-12、TC-INT-13；其余用例需完成上述数据准备。

## 用例

| 编号 | 测试项 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| TC-INT-01 | 导航入口 | 打开任意用户端页面，点击顶部“行业情报”。 | 页面跳转到 `/workspace/intelligence`；“行业情报”导航项为激活状态。 |
| TC-INT-02 | 深链接路由 | 在浏览器地址栏直接输入 `http://localhost:5175/workspace/intelligence`，然后刷新页面。 | 页面正常加载，无 404；页面标题为“行业情报”。 |
| TC-INT-03 | 初始加载 | 完成测试数据准备后打开行业情报页。 | 显示“匹配条目、主题聚类、情报简报”三个概览数值；条目流、主题聚类和简报列表均可加载。 |
| TC-INT-04 | 关键词筛选 | 在“关键词”输入一个已知的标题、行业或竞品关键词，点击“应用筛选”。 | 条目流仅显示标题或内容包含该关键词的结果；概览中的“匹配条目”数量同步变化。 |
| TC-INT-05 | 来源筛选与重置 | 从“来源”下拉框选择一个已加载来源，点击“应用筛选”；随后点击“重置”。 | 筛选后条目均来自选定来源；重置后关键词和来源恢复为空，条目流恢复默认结果。 |
| TC-INT-06 | 条目分页 | 准备超过 20 条情报，确认底部出现“加载更多”，点击该按钮。 | 已有条目保留，追加下一页条目；按钮在请求期间显示“加载中...”；总数与已显示数量正确。 |
| TC-INT-07 | 单篇摘要 | 在任意情报条目中点击“单篇摘要”。 | 右侧“智能摘要”显示摘要内容、风险提示和引用来源；引用来源可在新标签页打开。 |
| TC-INT-08 | 主题聚类与主题摘要 | 点击任意主题聚类卡片。 | 被选主题有高亮状态；右侧摘要标题变为该主题名称；摘要内容基于该主题关联条目生成。 |
| TC-INT-09 | 主题过滤 | 在“过滤主题”输入一个主题关键字，停顿约 1 秒。 | 聚类列表仅显示匹配主题；输入过程不会因每次按键频繁闪烁或阻塞。 |
| TC-INT-10 | 空数据状态 | 在尚未配置采集源或无采集结果的环境打开页面。 | 条目、聚类、简报区域分别显示清晰空态；不出现空白面板、报错堆栈或无限加载。 |
| TC-INT-11 | 简报查看 | 管理端生成日报和周报后，在用户端“情报简报”选择“日报”或“周报”，点击任一简报的“查看”。 | 列表仅显示对应周期简报；展开后显示覆盖条目数、主题数及主题摘要；再次点击可收起。 |
| TC-INT-12 | 数据加载失败与恢复 | 暂停 Python AI 服务后刷新页面，观察提示；恢复 Python 服务后点击错误提示中的“重新加载”。 | 页面给出“加载失败”及可操作的“重新加载”；恢复服务后可以正常加载，不需要刷新整个浏览器。 |
| TC-INT-13 | 用户权限边界 | 检查行业情报页面上的所有按钮、筛选项和链接。 | 用户端只包含查看、筛选、摘要和简报功能；不显示采集源新增/编辑/删除、手动采集、任务重试、生成简报等管理操作。 |
| TC-INT-14 | 响应式与可访问性 | 将浏览器宽度分别调整至约 375px、768px、1440px；使用 Tab 键依次访问筛选、摘要、简报操作。 | 小屏布局单列且无横向滚动；文字不重叠；焦点样式清晰；所有主要操作可通过键盘触达。 |

## 通过标准

- TC-INT-01 至 TC-INT-05、TC-INT-07 至 TC-INT-09、TC-INT-11 至 TC-INT-14 全部通过。
- 如当前没有采集数据，TC-INT-10 必须通过，其他依赖数据的用例记录为“待采集数据后复测”。
- 任一用例失败时，记录浏览器控制台错误、请求 URL、响应状态码和复现步骤。
