### 启动及回退

在 VM 上操作：

```sh
cd /home/zhb/apps/enterprise-ai-office-system-admin/deploy
./compose-models.sh ps
./compose-models.sh up -d --no-deps --no-build --pull never ai-service admin-server
docker restart eaos-gateway
```

新入口自动加载原三个 Compose 文件、新 `docker-compose.models.json` overlay
和 `.env.models`。不要仅用旧三个 Compose 文件启动，否则会恢复旧模型及镜像。
不要把未脱敏的 `docker compose config`、环境文件或 inspect 环境输出粘贴到聊天。

需要回退到原两个应用镜像时：

```sh
cd /home/zhb/apps/enterprise-ai-office-system-admin/deploy
./rollback-models.sh
```

回退脚本不回滚数据库、不删除新配置；后续应继续使用原配置，直至明确重新发布。
此次没有发生生产自动回退。应用回退流程尚未在切换后另行演练。
